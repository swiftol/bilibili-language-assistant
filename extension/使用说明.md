# B站语言助手 1.0.0

将“Bili Dual 双语耳机”和“B站日中英对照”合并为一个 Manifest V3 浏览器扩展。一个“语言助手”入口管理声音、字幕和网页语言对照。当前发布版为 1.0.0。

## 安装与更新

在 GitHub Releases 下载安装包并解压。Edge 打开 edge://extensions，Chrome 打开 chrome://extensions，开启开发人员模式，选择“加载解压缩的扩展”，选择包含 manifest.json 的文件夹，然后刷新 B站页面。

源码安装请选择本仓库的 extension 目录。更新时覆盖原目录，在扩展管理点“重新加载”，再刷新网页。

如果之前安装过“Bili Dual · 双语耳机”或“B站日中英对照”，先停用两份旧扩展再启用合并版，避免重复接管音频和重复显示译文。原本地设置继续使用。

## 使用

- 点击右下角“语言助手”打开面板，点面板外或“收起面板”关闭。
- 网页全屏和浏览器视频全屏时，入口、翻译设置及声音面板一起隐藏；字幕本身继续显示，退出全屏后恢复。
- 声音：将本片已有的官方音轨拖入左右耳，中间按钮交换耳位。播放器音量控制总音量，左右滑块调整各耳比例。需要立体声耳机，系统单声道应关闭。恢复按钮还原播放器原声。
- 字幕：从可用字幕栏拖入已开启栏，可排序、移除，并独立拖动字幕位置；保存单语和多语布局。
- 网页对照：在国内版及日语版已适配标题、动态、评论中补充官方可取得的其他语言，尽量保留原生布局。日英标题并排，默认去掉语言标签、各保留三行；设置中可显示全文、改行数或显示标签。
- 评论：短评论中文、英语、日语横排并以细竖线分隔；超过默认十行的长评论隐藏译文，可展开，阈值可调整。
- 假名：点击日语译文切换“日本語（にほんご）”形式，再点恢复。首次点击加载本地词典，之后复用。

## 范围和限制

声音及字幕接入 www.bilibili.com 的播放器；网页对照接入 www、t、space.bilibili.com。只使用当前视频官方提供的音轨、字幕和译文，不生成新配音、不调用外部 AI 翻译，不保证每个视频或评论都有三种语言。原声音轨目前按中文原声展示，非中文原声需自行确认。

B站页面结构和接口变化、接口限制、音轨地址过期、浏览器自动播放或跨域限制可能导致不可用。音轨准备失败会提示，自动切换官方语言作为回退时可能短暂改变播放器状态。切换视频会校验音轨归属，避免推荐预览音轨串入主视频。烧录字幕不能移动；原生画中画不保证显示自定义字幕层。

假名来自 Kuromoji/IPADIC 本地分词词典；人名、地名、新词和多音词可能误读，未知词保留原样。注音仍遵守标题三行省略设置。

## 数据与权限

不包含遥测、广告、后台服务器或外部翻译服务。插件读取匹配页面的 DOM 及相关官方接口响应，必要时以当前登录会话请求 B站音轨、字幕和译文；相关媒体由官方 CDN 提供。浏览偏好保存于页面本地存储，假名处理在本机进行。不会主动发布评论或视频。页面主环境中的脚本用于对接播放器及原生页面数据，浏览器隔离环境中的脚本用于声音控制、统一界面与本地词典。

## 验证情况

已在真实 B站页面确认网页全屏标记及原问题：声音宿主已隐藏，但独立翻译按钮仍显示。合并修复后的完整真实页面效果仍需更新后确认。

后台模拟浏览器通过：视频页/动态页单入口及控件合并、data-screen 和 body 网页全屏状态下全部入口隐藏及退出恢复、面板外点击关闭；官方请求签名、音轨归属和切换视频旧响应拒绝、左右耳交换及总音量、重复恢复启用；日语真实本地词典注音切换、标题省略、原卡片尺寸保留和长评论翻译折叠。

这不是 B站官方插件，不承诺所有页面与视频可用。
