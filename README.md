# B站语言助手

一个浏览器扩展，整合 **左右耳双语声音、自由字幕、日中英网页对照与日语假名**。

适用于桌面版 Edge / Chrome（Manifest V3）。这是社区实验性项目，与哔哩哔哩无隶属关系，未上架扩展商店。

## 下载与安装

在 [Releases](https://github.com/swiftol/bilibili-language-assistant/releases/latest) 下载 `bilibili-language-assistant-v1.0.0.zip`，解压后：

1. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
2. 开启“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择解压后**含有 manifest.json 的文件夹**，再刷新 B站页面。
4. 点击右下角“语言助手”。面板外点击可以关闭；网页全屏和视频全屏时插件面板隐藏。

如果从源码安装，选择本仓库的 **extension/** 文件夹。更新时覆盖原目录，再在扩展管理中点“重新加载”并刷新网页。

**从旧版本迁移：先停用旧的“双语耳机”和“日中英对照”，再启用此合并版，避免重复播放或显示。已有本地偏好沿用。**

## 功能

| 功能 | 行为 |
| --- | --- |
| 左右耳声音 | 将本片已有的官方音轨拖到左右耳，可交换语言；左右耳音量独立，播放器控制总音量 |
| 多语字幕 | 将可用字幕拖入已开启栏，可排序、移除、分别拖动位置，记忆单语及多语布局 |
| 网页三语 | 对已适配的视频标题、动态和评论补充官方提供的中文、日语、英语 |
| 卡片标题 | 原卡片布局保留，译文在下方日英并排；默认不显示语言标签，每种最多三行，可改行数或显示全文 |
| 评论对照 | 短评论横排并用竖线分隔；长评论译文默认折叠，可展开，默认十行阈值可自定义 |
| 日语读音 | 点击日语译文显示“日本語（にほんご）”，再次点击恢复；本地词典首次使用时加载 |
| 统一面板 | 一个入口管理声音、字幕与网页对照设置 |

完整操作、隐私说明和兼容限制见 [使用说明](extension/使用说明.md)。

## 先了解这些限制

- **不会生成新翻译或 AI 配音。** 仅接入 B站当前提供的音轨、字幕和译文，没有某种语言就不会凭空补齐。不同视频和评论的语言覆盖范围不同。
- 声音及字幕接入 `www.bilibili.com` 播放器；网页对照覆盖 `www`、`t`、`space.bilibili.com` 的已适配结构。并非所有页面类型都支持。
- 需要立体声耳机；系统单声道会影响左右耳分离。非中文原声视频需自行确认语言，当前原声槽位按中文原声展示。
- B站接口限制、页面更新、地址过期、浏览器自动播放与跨域限制可能造成音轨取得失败、超时或字幕不可用。官方语言切换回退可能短暂改变播放器状态。
- 烧录在画面里的字幕不能拖动；原生画中画不保证显示自定义字幕。
- 假名由本地 Kuromoji/IPADIC 分词词典生成，专有名词、新词、多音词可能误读；未知词保留原文。注音仍受标题行数设置限制。
- 这是实验性初版。已做真实页面观察和模拟浏览器回归，**尚未完成所有页面与视频的端到端兼容验证**。

## 隐私与权限

不包含遥测、广告、外部翻译服务或项目后台。扩展在匹配的 B站页面中读取 DOM 和相关官方接口响应，必要时使用当前登录会话向 B站请求音轨、字幕及译文，并从官方媒体 CDN 播放媒体。偏好保存在页面本地存储，假名在本机处理，不上传评论用于注音，不主动发帖或发评论。

脚本分别运行于页面主环境与浏览器隔离环境，用来对接原生播放器、控制音频和加载本地词典。安装时浏览器会提示匹配站点的页面访问范围。

## 开发与测试

安装包可直接加载，使用插件不需要 Node.js。开发检查：

```sh
npm ci
npx playwright install chromium
npm run check
npm test
```

也可以设置 `CHROME_PATH` 指向已有 Chrome 可执行文件。测试通过模拟页面和接口验证音轨签名/归属、左右耳路由与总音量、原生卡片布局、标题省略、评论折叠、本地注音及全屏控件隐藏；**测试通过不等于所有真实 B站页面都已验证**。测试输出保存在忽略的 `artifacts/`，不包含用户浏览数据。

问题反馈请注明扩展版本、浏览器版本、页面类型和复现步骤；不要提交 Cookie、令牌或个人信息。
