# B站语言助手

一个浏览器扩展，整合 **左右耳双语声音、自由字幕、日中英网页对照与日语假名**。

适用于桌面版 Edge / Chrome（Manifest V3）。这是社区实验性项目，与哔哩哔哩无隶属关系，未上架扩展商店。

## 下载与安装

在 [Releases](https://github.com/swiftol/bilibili-language-assistant/releases/latest) 下载 `bilibili-language-assistant-v1.4.53.zip`，解压后：

1. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
2. 开启“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择解压后**含有 manifest.json 的文件夹**，再刷新 B站页面。
4. 点击右下角“语言助手”。面板外点击可以关闭；网页全屏和视频全屏时插件面板隐藏。

如果从源码安装，选择本仓库的 **extension/** 文件夹。更新时覆盖原目录，再在扩展管理中点“重新加载”并刷新网页。

**从旧版本迁移：先停用旧的“双语耳机”和“日中英对照”，再启用此合并版，避免重复播放或显示。已有本地偏好沿用。**

## 功能

| 功能 | 行为 |
| --- | --- |
| 左右耳声音 | 将本片已有的官方音轨拖到左右耳，可交换语言；左右耳音量独立，播放器控制总音量 |
| 多语字幕 | 将可用字幕拖入已开启栏，可排序、移除、分别拖动位置，记忆单语及多语布局 |
| 网页三语 | 对已适配的视频标题、动态和评论补充官方提供的中文、日语、英语 |
| 卡片标题 | 原卡片布局保留，译文在下方日英并排；默认不显示语言标签，每种最多三行，可改行数或显示全文 |
| 评论对照 | 短评论横排并用竖线分隔；长评论译文默认折叠，可展开，默认十行阈值可自定义 |
| 日语读音 | 点击日语译文显示“日本語（にほんご）”，再次点击恢复；可见日语在页面空闲时预先准备本地读音 |
| 统一面板 | 一个入口管理设置、字体大小、声音与收录仓夹 |

「字体大小」中，视频字幕、弹幕、评论区和网页文字都可用滑块或直接输入数值，并即时预览中日英三种字号。网页文字可切换区域，清空评论区或网页文字的数值可恢复对应默认字号。 四类文字的分行间距均可调至 0–24 px，默认 0 px，网页间距按区域记忆。中日英弹幕字号各支持 20%–300%。

完整操作、隐私说明和兼容限制见 [使用说明](extension/使用说明.md)。

## 先了解这些限制

- **不会生成新翻译或 AI 配音。** 仅接入 B站当前提供的音轨、字幕和译文，没有某种语言就不会凭空补齐。不同视频和评论的语言覆盖范围不同。
- 声音及字幕接入 `www.bilibili.com` 播放器；网页对照覆盖 `www`、`t`、`space.bilibili.com` 的已适配结构。并非所有页面类型都支持。
- 需要立体声耳机；系统单声道会影响左右耳分离。非中文原声视频需自行确认语言，当前原声槽位按中文原声展示。
- B站接口限制、页面更新、地址过期、浏览器自动播放与跨域限制可能造成音轨取得失败、超时或字幕不可用。官方语言切换回退可能短暂改变播放器状态。
- 烧录在画面里的字幕不能拖动；原生画中画不保证显示自定义字幕。
- 假名由本地 Kuromoji/IPADIC 分词词典生成，专有名词、新词、多音词可能误读；未知词保留原文。注音仍受标题行数设置限制。
- 这是实验性初版。已做真实页面观察和模拟浏览器回归，**尚未完成所有页面与视频的端到端兼容验证**。

## 隐私与权限

不包含遥测、广告、外部翻译服务或项目后台。扩展在匹配的 B站页面中读取 DOM 和相关官方接口响应，必要时使用当前登录会话向 B站请求音轨、字幕及译文，并从官方媒体 CDN 播放媒体。偏好保存在页面本地存储，假名在本机处理，不上传评论用于注音，不主动发帖或发评论。

脚本分别运行于页面主环境与浏览器隔离环境，用来对接原生播放器、控制音频和加载本地词典。安装时浏览器会提示匹配站点的页面访问范围。

## 开发与测试

安装包可直接加载，使用插件不需要 Node.js。开发检查：

```sh
npm ci
npx playwright install chromium
npm run check
npm test
```

也可以设置 `CHROME_PATH` 指向已有 Chrome 可执行文件。测试通过模拟页面和接口验证音轨签名/归属、左右耳路由与总音量、原生卡片布局、标题省略、评论折叠、本地注音及全屏控件隐藏；**测试通过不等于所有真实 B站页面都已验证**。测试输出保存在忽略的 `artifacts/`，不包含用户浏览数据。

问题反馈请注明扩展版本、浏览器版本、页面类型和复现步骤；不要提交 Cookie、令牌或个人信息。

## 本机 1.0.2 修复

字幕只显示语言条中选中的语言。例如仅选英语、日语时，本片都没有就不显示字幕；不会补成中文。缺少所选外语音轨或两耳都为原声时，保留播放器原来的左右声道，不进行单声道混音。

## 本机 1.0.3 播放器内控制

播放器控制栏的“双语”打开字幕与左右耳声音。字幕语言仍使用拖放选择；位置直接拖动视频中的字幕，取消位置滑条，支持重置。字号有小/标准/大，且随实际画面缩放；位置按比例保存，单语/多语位置分别记忆。网页全屏、浏览器全屏均可打开面板，点击外部或再次点击入口收起。网页对照设置保留在可展开项内。

自动测试覆盖缩放、黑边、拖动抓取点、位置保存、重置和全屏切换。可选 npm run test:live 使用独立无登录浏览器访问真实 B 站页面，只检查入口与面板布局，不代表已在用户当前登录页面重载扩展。需要重新加载扩展并刷新页面才能启用新的播放器入口。

## 本机 1.0.4 数字字幕字号

字幕字号改为数字输入框，显示当前画面的实际像素字号，支持直接输入 1–200 px、输入框上下箭头及键盘上下键，每次 1 px。字号仍随画面缩放，并保存缩放比例；可以继续缩小，不再受“小”预设限制。

## 本机 1.1.0：收藏轮盘与声音分支

- 按住原生收藏键约 240 毫秒，或按下后拖动超过 10 像素：显示收藏轮盘。拖向目标并松手收藏；中心松手或 Esc 取消。普通点击保留原收藏弹窗。
- 播放器面板底部“收藏轮盘设置”可勾选最多 8 个常用收藏夹。第一次没有配置时展示前 6 个，此后按本机使用次数优先。每个登录账号分别记忆。已收藏只提示，不会再次取消。
- 按住“双语”入口，向上拖向中日／中英／原声。中日和中英均为左耳外语、右耳原声；缺配音时保留原声。普通点击仍打开设置面板。
- 收藏请求始终重新核对当前视频、账号与收藏夹归属，且只发送添加，不发送删除。登录令牌只留在页面接口层，不传到手势界面或测试报告。

### 后台测试

运行 npm run test:background。自动检查并同步安装文件，使用独立无界面的 Chrome for Testing，从 manifest 加载完整扩展，然后运行手势测试及真实 B 站播放器检查；不使用日常浏览器的登录资料，不触碰用户真实收藏。失败会保留日志、截图和 Playwright trace；通过结果可见 artifacts/background-latest.json。可用 BILI_TEST_HOME 指定测试浏览器和报告存放目录。

收藏写入的成功、重复收藏、失败、未登录与导航取消使用隔离的模拟接口测试。真实页面检查入口与播放行为，不代表已完成真实登录账号的收藏写入验证。

## 本地开发版 1.2：收藏轮盘编辑

长按收藏键后拖到收藏夹，松手收藏；短按保持 B站原收藏窗口。外部“语言助手 ⚙”面板和浏览器右上角插件弹窗均可配置，同账号配置共享。

从可用收藏夹拖到某层的“＋”间隙插入，6 项变 7 等分；从轮盘拖回可用区移出，6 项变 5 等分。层内拖动重排，跨层拖动移动；支持撤销。移出和清空仅修改快捷布局，不删除收藏夹或已有收藏。

可增加空白层，逐个拖入所需收藏夹；可调整每层旋转角度及同时显示层数。默认首层 6 项、次层最多取后续 16 项；实际按项目数等分。每层最多 64 项，层数不设固定上限，显示不下时长按期间滚轮翻层。

“同时收藏到默认收藏夹”默认开启：例如选“233”，同时加入“233”和系统默认收藏夹，可关闭或指定另一个汇总收藏夹；不会取消已有收藏。未登录会提示登录，无法识别默认夹时先提示配置再写入。

后台验证：`npm run test:background` 使用独立无头浏览器加载实际扩展，覆盖拖入/拖出/跨层、弹窗同步及真实 B站播放器。收藏 API 写入由测试数据拦截，不修改真实账号收藏。

开发更新约定：每次向本机分发有行为变化的扩展时递增 manifest、package 和 lockfile 版本，并在 CHANGELOG 记录；检查脚本会校验这些版本一致。


### 弹幕翻译与字幕位置（1.3.0）

弹幕中英日对照默认关闭，开启后读取 B站弹幕接口已有译文，并按弹幕 ID 配对。短弹幕横排、长弹幕分三行；译文缺失、重复文本有歧义或可能遮挡时保留原文。

拖动翻译字幕后按 UP 主 UID 保存单语与多语位置；新 UP 主沿用之前的默认位置。无法识别 UP 主时按视频暂存位置，识别后可合并。

主页标题译文优先加载屏幕内卡片，在同一标签页短期缓存最多 200 条标题（有效期 6 小时）；译文可用性与速度仍取决于 B站接口。

收藏轮盘中绿色表示已收藏、灰色表示未收藏；对已收藏的文件夹再次松手只取消该文件夹的收藏，其他文件夹（包括自动收藏的默认夹）保持不变。拖到「中日」或「中英」下方的 ⇄ 小节点松手，即可交换该组合的左右耳。选主节点会保留当前组合的耳位。
